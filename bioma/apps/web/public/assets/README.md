# Assets do Bioma

Coloque aqui os arquivos visuais servidos pelo frontend.

## Estrutura sugerida

```text
assets/
  brand/
    eg-logo.svg
    eg-logo-dark.svg
    eg-symbol.svg
  clients/
    hm-conexoes/
      logo.svg
      login-background.webp
      avatar-henrique.webp
```

## Formatos

- Logos: `svg` preferencial; `png` com fundo transparente se não houver vetor.
- Fotos/avatares: `webp` ou `jpg`.
- Fundos/hero: `webp`.

## Proporções úteis

- Logo horizontal: `4:1` ou `3:1`.
- Símbolo/avatar: `1:1`.
- Fundo de login/hero: `16:9`, mínimo `1920x1080`.
- Imagem de cliente ou pessoa: `1:1`, mínimo `512x512`.
