# Bioma Web

Frontend do Bioma MVP v0.

## Rodar local

```bash
npm install
npm run dev
```

## Validar

```bash
npm run build
```

O build executa `tsc -b` e `vite build`. Por enquanto ele é o smoke mínimo do frontend. O próximo passo de qualidade é adicionar um teste visual/manual documentado com desktop, notebook com DevTools aberto e mobile.
